# Native stereo matching delay foundation — 2026-11-24

Additive, causal, filtered stereo delay with bounded feedback, optional cross-feedback, dry M/S gain, and a separately smoothed wet return. This is not a full preset or an identified model of any owner's recording. Fixed delay/routing per prepared recipe; wet changes from the audio thread, no allocations in process. Zero transport latency refers to the immediate dry path, not the intentional echo time. No clipping or loudness normalization is applied. Prepare/reset off the audio thread.

Local GNU C++ 14.2, C++17 -O2 -Wall -Wextra -Werror: targeted synthetic test passed across 44.1/48/96/192 kHz with exact block schedules 1/64/256/511/1024, cross-feedback impulse timing, M/S gain, finite handling, invalid parameter rejection and reset. ## Native standalone renderer

Build SkellCoreMatchStereoDelayRender with SKELLCORE_BUILD_NATIVE_MATCH_RENDERER enabled. Transport is native-endian interleaved stereo float32, source only. Arguments: input.f32 output.f32 rate delayMs cutoffHz feedback cross wet midGain sideGain block. Existing output, malformed geometry, nonfinite input, fractional block/rate, invalid feedback and other invalid settings are rejected. Version: match-stereo-delay-v1. Real paired stage experiments used the actual C++ header for every candidate, with a local C ABI fitting harness. The standalone CLI produced identical sample hashes to the fitting harness for six frozen recipes, across 1/64/256/511/1024 blocks. Targeted GNU C++ 14.2 -O2 -Wall -Wextra -Werror build passed. Sample hashes, fitted parameters and private recordings are not published. A same-take diagnostic is not independent approval; unsafe or non-improving outputs remain rejected.
