# R75 causal matching dynamics (experimental)

Additive reusable DSP for sound matching, from Sound Match R74 control curve, commit 54b9dd602234344b03e7fe45bc166d4bfdc56054. CausalMatchCompressor consumes completed input-only detector frames with stereo linking and a forward gain ramp. It does not buffer the audio signal or use future samples; latencySamples=0 refers to standalone algorithmic signal delay, not host PDC. Fixed settings only; configure outside the callback. Do not substitute for existing compressor models or expose unverified FL raw mappings.

GCC strict O3 and ASan/UBSan passed 135 combinations (32/44.1/48/96/192 kHz, three detector domains, three detector types, periods 1/16/64); block split, reset, causal prefix, stereo link and finite-input handling. No heap in the process code; instrumented allocation/host CPU verification still outstanding.
